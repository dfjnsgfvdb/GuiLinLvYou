# Liguan Tourism Console

Vue 3 frontend for the Liguan Guilin tourism public-opinion intelligence platform.

```bash
pnpm install
pnpm dev
```

The development server runs on `http://127.0.0.1:2048` and proxies `/sanic` to the Sanic API on port `8088`.

See the [project README](../README.md) for the complete setup and architecture.
